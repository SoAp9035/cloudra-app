# Getting Started

Run these commands to start building:
```
git clone https://github.com/SoAp9035/selcuk-space-app.git
cd selcuk-space-app
```

## How to run

```
uv run main.py
```

To stop the running project press: CTRL + C

## How to update the project

```
git pull https://github.com/SoAp9035/selcuk-space-app.git
```
